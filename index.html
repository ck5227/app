高陰離子隙代謝性酸中毒的決策輔助：解析檢驗值與用藥清單，並列評分可能病因、 標示缺漏檢驗、評估體外清除指徵。純本地運算，無外部 API。

這是 Streamlit 應用，GitHub Pages 只能放靜態檔案， 無法在這裡執行。下載 app.py 後在本機跑：

pip install -r requirements.txt
streamlit run app.py
