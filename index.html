臨床教學工具

急診與臨床毒物學的教學小工具。僅供教育用途，不取代臨床判斷。

值班 03:00 可直接遊玩

高陰離子隙代謝性酸中毒的鑑別診斷訓練。五個情境（MALA、甲醇中毒、eDKA、 壞死性軟組織感染、水楊酸中毒），每個動作都消耗時間，病人的外觀與生命徵象 會隨時間改變。結算檢討的是推理過程，不是結果。

急診頭暈流程 精簡版

神經學檢查 → 時序與誘發分型 → 自發性眼振型態 → HINTS 或 Dix-Hallpike。 垂直或扭轉型眼振、持續性眩暈卻無眼振，均直接導向中樞處置。 每一步標示 GRACE-3 之建議強度並可展開原始出處。

開啟 →

急診主訴導航 頭暈・腹痛・發燒

三組並列：最符合／最常見、最嚴重・不能漏、其他鑑別。 資料不足時以有出處的盛行率補位；位置、年齡等弱線索不會單獨把危險診斷推成「最符合」。 引用來源包括 GRACE-3、NICE NG126、WSES 2022、ACC/AHA 2025、AFP 2023 等， 每條建議可展開原始出處，未查證者自動封鎖。支援手機與深色模式。

學習歷程代碼彙整 教師端

把學員在「值班 03:00」結算頁回填的代碼整批貼入，產生個別表現與全班統計 （診斷正確率、關鍵資訊取得率、低產出耗時等），可匯出 CSV 做課程成效分析。 純前端運算，資料不離開操作者的電腦。

AcidoScope 需本機執行

高陰離子隙代謝性酸中毒的決策輔助：解析檢驗值與用藥清單，並列評分可能病因、 標示缺漏檢驗、評估體外清除指徵。純本地運算，無外部 API。

這是 Streamlit 應用，GitHub Pages 只能放靜態檔案， 無法在這裡執行。下載 app.py 後在本機跑：

pip install -r requirements.txt
streamlit run app.py
